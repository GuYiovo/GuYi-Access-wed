## 三、验证接口清理（修复误入云黑）

**问题：**  
残留的 iOS WebApp 环境校验 + 可被客户端直接调用的云黑接口，容易导致正常用户（含 PC 易语言对接）被莫名拉入云黑。

**处理：**

1. 删除 `Database.php` → `verifyCard()` 中全部 iOS WebApp / `client_language=php` 环境拦截逻辑
2. `Verify.php` 去掉 `client_language` 解析与传递
3. 云黑接口 `action=ban_machine` / `blacklist` **必须带管理端 `api_token`**，禁止客户端自助拉黑
4. 验证只负责正常通讯（鉴权、卡密、设备绑定、过期、黑名单查询等）；反逆向交由用户客户端自行处理

**上线后建议：**

- 在后台「防御与拉黑」清理历史误封 IP/设备
- 若易语言对接包里还有调用云黑接口的代码，一并删除

## 四、登录「页面已过期」修复

**原因：**  
Session Cookie 未强制 `path=/`，在 `/login/` 下启动 session 时 path 变成 `/login/`，导致 CSRF 校验失败。

**修复：**

- `app/Auth/LoginController.php`：强制 `session_set_cookie_params(path=/)`，正确识别 HTTPS，避免重复 `session_start`
- `app/Admin/Controller.php`：同样处理，保证进后台 session 不丢
- `resources/views/auth/login.php`：表单 `action=""`，减少入口路径问题
- `config/config.php` / `scripts/install.php` 生成配置同步更稳健的 session 设置
- `app/Api/Captcha.php` 同步处理

覆盖后需清除该站点 Cookie（或无痕）再登录。

## 十、登录页 / 全局背景改回图片壁纸

**问题：**  
登录页与后台「全局动态背景」被改成 mp4 视频，开启后台背景后布局易出现镂空、可读性变差。

**处理：**

1. 登录页背景改回图片接口：
   - PC：`https://www.loliapi.com/acg/pc/`
   - 移动端：`https://www.loliapi.com/acg/pe/`
2. 自动忽略数据库中历史遗留的 `.mp4` 背景地址
3. 后台「全局背景」同样改为上述图片壁纸（不再使用视频）
4. 开启背景后：
   - 侧边栏保持较高不透明度
   - 顶栏 / 卡片半透明设下限，减少布局「透穿」感
5. 设置项文案由「开启全局动态背景」调整为「开启全局背景」

涉及文件：

- `app/Auth/LoginController.php`
- `resources/views/auth/login.php`
- `resources/views/admin/layout/header.php`
- `resources/views/admin/pages/settings.php`
